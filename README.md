# Excel Lab — Workplace Simulator & Corporate Interview Prep

> **Platform Simulasi Interaktif & Tes Uji Praktik Rumus Excel Berstandar Seleksi Masuk Kerja BUMN & Korporasi Indonesia.**

🔗 **Live Demo Online:** [https://zwart04.github.io/excel-lab/](https://zwart04.github.io/excel-lab/)

---

## 🌟 Fitur Utama

- **32 Skenario Nyata Dunia Kerja Indonesia**: Terbagi dalam 4 divisi korporat (Sales & Marketing, Keuangan & Akuntansi, Administrasi & Operasional Gudang, serta Human Resources & Payroll).
- **Maskot Manajer 3D Interaktif & Percakapan Suara Prosedural**: Maskot 3D Three.js dengan dialog briefing komik dan efek suara sintesis khas simulasi modern.
- **In-Cell Formula Engine Khas Microsoft Excel**: Pengetikan rumus langsung di dalam sel (`=SUMIF`, `=VLOOKUP`, `=IF`, `=COUNTIF`, `=AVERAGE`), autocomplete nama fungsi, serta penutup tanda kurung otomatis (*auto-close parentheses*).
- **Mode Simulasi Ujian Kerja (Timer 15 Menit)**: Uji ketangkasan menyelesaikan kasus spreadsheet di bawah tekanan waktu tes rekrutmen.
- **Sertifikat Kompetensi Digital Resmi**: Template sertifikat berbingkai ganda emas, nomor kredensial unik, stempel terverifikasi, serta fitur **Cetak / Simpan PDF (A4 Landscape)** untuk portofolio LinkedIn & CV.
- **Buku Saku & Cheat Sheet Rumus**: Panduan cepat rumus interview kerja dan bedah *5 Jebakan Paling Sering Terjadi di Tes Masuk BUMN/Perusahaan*.
- **Desain Apple Human Interface Guidelines (Anti-Slop)**: Tipografi SF Pro, glassmorphism, 100% ikon vektor SVG tanpa emoji, dan tata letak responsif desktop & mobile.
- **Penyimpanan Lokal Otomatis (*Offline-Ready*)**: Progres latihan, XP, streak, dan nama sertifikat tersimpan aman di peramban tanpa memerlukan backend server.

---

## 💻 Menjalankan Secara Lokal

Buka file `index.html` langsung di browser favorit Anda, atau jalankan server lokal:

```bash
# Python 3
python3 -m http.server 8000

# Buka http://localhost:8000 di browser
```
